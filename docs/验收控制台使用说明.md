# 验收控制台使用说明

验收控制台用于载入作业验收用例、控制模拟时间、执行事件、记录状态快照，并导出表格视图。入口为管理端的“验收控制台”页面。

## 使用前提醒

1. 在验收控制台中初始化数据库、开启或关闭验收模式后，其他已打开页面的登录态和运行上下文可能不会立即同步，需要重新登录后才能生效。因此点击“开始执行”前，先重新登录管理端，并设置好调度模式、故障策略等参数，例如时间顺序调度模式或优先级调度模式。
2. “下个事件演示”功能暂时有 bug，验收时先不要使用。

## 基本流程

1. 进入验收控制台。
2. 点击“初始化数据库”，重置验收用的用户、车辆、充电桩、事件和快照数据。
3. 点击“启用验收模式”，让用户端、管理端和调度计费逻辑统一使用模拟时间。
4. 重新登录需要观察或操作的管理端、用户端页面。
5. 在管理端设置本次验收需要的调度模式和故障策略。
6. 在验收控制台载入 xlsx 用例，检查识别出的事件列表。
7. 如有需要，修正事件时间、车辆编号、充电类型、充电量、故障桩位或事件启用状态。
8. 使用“开始执行”“执行到下一事件”或“立即执行至最终态”推进样例。
9. 在“执行总览”“快照历史”“表格视图”中检查每个事件后的系统状态。
10. 需要提交结果时，在“表格视图”点击“导出 xlsx”。

## 常用按钮

| 按钮 | 作用 |
|------|------|
| 初始化数据库 | 清空并重建验收运行数据 |
| 启用验收模式 | 开启全局模拟时间和验收事件记录 |
| 关闭验收模式 | 恢复普通运行模式 |
| 选择文件 / 解析样例 | 载入并识别 xlsx 验收用例 |
| 确认事件列表 | 保存识别或修正后的事件 |
| 跳转 | 将模拟时间定位到指定时刻 |
| 开始执行 | 从当前模拟时间开始自动推进 |
| 执行到下一事件 | 推进到下一条待执行事件并执行 |
| 暂停执行 | 暂停自动推进 |
| 立即执行至最终态 | 快速执行剩余事件并推进到最终状态 |
| 导出 xlsx | 导出表格视图结果 |

## 查看结果

- “执行总览”用于观察当前事件队列、充电桩队列、等候区和故障队列。
- “快照历史”用于对比某个事件执行前后的状态。
- “表格视图”用于查看按验收表格整理后的状态，导出的 xlsx 与该视图口径一致。
- 故障队列不占用普通等候区容量，会在总览、表格视图和导出文件中单独标明。

## 手动操作

验收模式开启后，可以在用户端或管理端进行手动操作，例如提交请求、修改请求、取消请求、提前结束充电、设置故障或恢复故障。

- 暂停状态下的手动操作会登记为当前模拟时刻的待执行事件。
- 运行状态下的手动操作会直接执行，并记录到事件列表和表格快照中。
- 手动操作后如其他页面状态没有更新，先刷新页面；若刚初始化或刚切换验收模式，则重新登录。
